# 明日简短汇报稿（约 1 分钟）

我选择的是第一个题目：**基于非线性优化的 BLE 众包离线设备高精度定位**。

我把大题收缩为一个可验证的应用数学子问题：当帮助设备的坐标存在漂移、BLE 测距受到 NLOS 异常影响、部分帮助设备不稳定时，怎样通过鲁棒非线性优化降低二维定位误差，重点观察 CEP90。

方法上，我会先实现普通非线性最小二乘作为基线，再实现 Huber/Cauchy 迭代重加权最小二乘，并加入基于元数据、残差和时间稳定性的帮助设备可靠性权重。

智能体部分会采用 LangGraph。它不直接编造结果，而是读取验证集的误差切片，在严格白名单内提出一次方法或参数改动，调用固定的仿真和评测工具，再把采纳或拒绝的原因写入迭代日志。测试集不会参与调参。

目前的阶段性成果是已确定问题公式、数据生成方案、评价指标和智能体状态图。后续将完成四轮可复现实验，最后输出 GitHub 代码、迭代日志以及包含 CEP90 曲线的 PDF。由于先使用合成数据，我不会宣称完成华为的真实 KPI，真实数据验证会作为后续工作。
