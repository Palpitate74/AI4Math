# 中期简短进展汇报（约 1 分钟）

我选择的是 BLE 众包离线位置聚合，把大题收缩为合成数据上的二维静态目标定位：在 NLOS、帮助设备坐标漂移和退化几何下，用既有鲁棒非线性优化降低误差，重点看 CEP90。这不是移动目标检测，也不是新算法或真实工业验收。

目前已实现 LangGraph 的受限实验闭环：模型看验证结果提出单一白名单改动，Python 工具求解，固定规则采纳或拒绝并记录证据。真实 run `deepseek-midterm-20261116` 完成四轮候选评估，第五轮三个无效提案被阻断，共保留八次 DeepSeek 响应；不是五次有效实验或八轮实验。第二、三轮的预期改善被实际 CEP90 推翻，说明模型理由不是证明。

最终选择 Huber+时间稳定性权重。384 次 holdout 上 CEP90 为 11.6754 米，NLS 为 19.4654 米；固定场景混合的配对百分位 bootstrap 支持该误差差值在零以下，但失败率差区间跨零，不能确认失败率收益。原始日志、误差和中文八页 PDF 都可复核；已有 run 后补快照只能叫事后核验，不夸称事前完整登记。下一步做等预算搜索对照和真实授权数据验证，暂不宣称 LLM 优于网格或满足 Huawei KPI。
