# 研究问题与边界

## 来源与选题

本项目选择《HarmonyOS难题发布-第七期》难题 1：**基于非线性优化的众包离线高精度位置聚合难题**。

原问题要求从多个“好心人”设备的定位位置、BLE RSSI 及可信度等信息中，估计离线设备位置：

\[
\hat{x}=\arg\min_x\sum_{i=1}^N\omega_i\left(f(r_i)-\|x-l_i\|_2\right)^2.
\]

其中，`l_i` 是第 `i` 个帮助设备的报告位置，`f(r_i)` 是 RSSI 转距离函数，`ω_i` 是报告可靠性权重。

## 本项目的可验证子问题

在二维平面上，当观测含有以下污染时，比较普通非线性最小二乘与鲁棒/可靠性加权方法的定位误差：

- RSSI 距离噪声；
- NLOS 导致的正偏大误差；
- 帮助设备上报位置漂移或移动；
- 帮助设备空间分布不佳；
- RSSI 校准偏差。

提出的方法为“鲁棒损失 + 交替可靠性更新”：先进行 Huber/Cauchy 鲁棒拟合，再根据元数据、残差和时间稳定性更新每个帮助设备的权重。
